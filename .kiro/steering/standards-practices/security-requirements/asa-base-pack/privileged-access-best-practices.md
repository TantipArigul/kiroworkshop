# Privileged Access Best Practices

**Pack:** ASA Base Pack  
**Description:** Ensure there are adequate guardrails for privileged functions.

## Domain / Applicability

Applies to systems with administrative functions or elevated privileges.

## Evaluation Criteria

A compliant system should have clearly defined administrative roles, activity logging for administrative actions, and administrative privileges limited to only necessary operations.
To help evaluate compliance, a document should describe who has administrative access, what privileges they have, and how their actions are monitored.
A system is clearly non-compliant if it allows unrestricted administrative access, lacks audit logging of administrative activities, or grants excessive privileges that violate least-privilege principles.
