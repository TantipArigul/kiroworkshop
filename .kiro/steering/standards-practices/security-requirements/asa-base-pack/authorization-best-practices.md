# Authorization Best Practices

**Pack:** ASA Base Pack  
**Description:** Ensure systems follow authorization best practices.

## Domain / Applicability

Applies to systems that distinguish between multiple users or clients, including both human users and programmatic callers.

## Evaluation Criteria

A compliant system should have clearly defined access controls that enforce least privilege, separate different types of users/clients, and restrict access to resources and actions based on legitimate need.
To help evaluate compliance, a document should describe what actions different users can perform, what resources they can access, and how access control decisions are made and enforced.
A system is clearly non-compliant if it lacks meaningful access restrictions, fails to distinguish between different user types, or allows users to access resources or perform actions beyond their legitimate needs.
