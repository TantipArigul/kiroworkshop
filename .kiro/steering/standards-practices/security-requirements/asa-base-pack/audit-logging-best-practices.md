# Audit Logging Best Practices

**Pack:** ASA Base Pack  
**Description:** Ensure the system supports security monitoring.

## Domain / Applicability

Applies to systems whose users can see sensitive data or perform consequential actions.

## Evaluation Criteria

A compliant system should generate logs that record system changes, access attempts, and user activities at appropriate detail levels for security monitoring and incident investigation.
To help evaluate compliance, a document should describe what events are logged, what information is captured for each event, and how completeness of logging is maintained.
A system is clearly non-compliant if it fails to log security-critical events, omits essential details from log entries, or has gaps in logging coverage that would hinder investigations.
