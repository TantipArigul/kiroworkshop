# ASA Base Pack

**Pack ID:** srp-am-base  
**Description:** Default security requirements shipped with AWS Security Agent  
**Total Requirements:** 10  
**Source:** AWS Security Agent (Agent Spaces, ap-southeast-1)

## Requirements

| # | Name | Description |
|---|------|-------------|
| 1 | audit-logging-best-practices | Ensure the system supports security monitoring. |
| 2 | authentication-best-practices | Ensure only legitimate users can access the system. |
| 3 | authorization-best-practices | Ensure systems follow authorization best practices. |
| 4 | information-protection-best-practices | Ensure sensitive data remains confidential and unaltered. |
| 5 | log-protection-best-practices | Protect the integrity and confidentiality of system logs. |
| 6 | privileged-access-best-practices | Ensure there are adequate guardrails for privileged functions. |
| 7 | secret-protection-best-practices | Ensure that secrets like credentials remain confidential. |
| 8 | secure-by-default-best-practices | Ensure the system's default configuration is secure. |
| 9 | tenant-isolation-best-practices | Ensure appropriate separation between system tenants. |
| 10 | trusted-cryptography-best-practices | Ensure only trustworthy cryptographic implementations are used. |
