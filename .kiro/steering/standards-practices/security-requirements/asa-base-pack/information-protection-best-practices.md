# Information Protection Best Practices

**Pack:** ASA Base Pack  
**Description:** Ensure sensitive data remains confidential and unaltered.

## Domain / Applicability

Applies to systems that store or transmit data that should be kept confidential or protected from tampering.

## Evaluation Criteria

A compliant system should keep sensitive data confidential during storage and transmission through appropriate encryption. It should maintain data integrity and prevent unauthorized modifications.
To help evaluate compliance, a document should identify what data needs protection, when encryption is required, and how data integrity is maintained.
A system is clearly non-compliant if it stores or transmits sensitive data without encryption, lacks integrity controls for important data, or fails to identify and protect sensitive information.
